# Operations — build, test, release, environments

## Local dev (this machine: Windows Server 2019, C:\Users\digi)

- Go toolchain: `C:\Users\digi\tools\go\bin\go.exe` (1.26.5, installed from
  zip — NOT on system PATH; prepend it in each shell:
  `$env:PATH = "C:\Users\digi\tools\go\bin;$env:PATH"`).
- Repo: `C:\Users\digi\dig\digi-erp-connector` (siblings: the two read-only
  parent repos `electron-mssql-app` and `erp-connector`).

```powershell
go build ./...        # everything, incl. walk GUI (windows)
go vet ./...
go test ./...
go build -trimpath -ldflags "-s -w -H=windowsgui" -o digi-erp-connector.exe ./cmd/digi-erp-connector
go build -trimpath -ldflags "-s -w" -o digi-erp-connectord.exe ./cmd/digi-erp-connectord
```

`*.exe` is gitignored — never commit binaries.

## GitHub / release pipeline

- Remote: https://github.com/digitrade-e/digi-erp-connector (default branch `main`).
- **Every push to `main` auto-releases**: `auto-tag` bumps the patch version
  (v1.0.0, v1.0.1, ...) → `release-windows` builds both EXEs, downloads
  PDFtoPrinter + qpdf29.dll + resource.dat, compiles the Inno Setup
  installer, publishes a GitHub Release. Don't push half-finished work to main.
- Installer asset name: `digi-erp-connector-setup-<version>.exe`.

## Git auth on this machine (important)

## Runtime environments (customer machines)

- Install via the release installer (admin). It registers + starts the
  `digi-erp-connectord` service (auto-start) and adds a desktop shortcut that
  elevates the GUI via `launch-admin.vbs`.
- Data dir: `%PROGRAMDATA%\digi-erp-connector\` — `config.yaml` (0600, bearer
  token in plaintext), `queries.json`, `server.log`, `ui.log`, `secrets\`
  (DPAPI machine-scope: `db_password_<erp>.bin`, `smtp_password.bin`).
- The old erp-connector (`erp-connectord` service, `%PROGRAMDATA%\erp-connector`)
  can coexist during transition — different service name, dir, installer AppId.
- Order-number continuity: copy `lastOrderNumber.json` from the old install's
  SendOrderDir if switching an existing Hasavshevet customer.
